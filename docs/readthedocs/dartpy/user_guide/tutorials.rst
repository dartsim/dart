Tutorials
=========

Learning resources
------------------

Start with the :doc:`dartpy examples </dartpy/user_guide/examples>` to load a
robot model and run a simulation. Additional runnable Python examples are in
the `source repository <https://github.com/dartsim/dart/tree/main/python/examples>`_.

The :doc:`C++ tutorials </dart/user_guide/tutorials>` explain general DART
concepts that apply to both C++ and Python APIs. Their code is written in C++;
use the dartpy examples for Python code.
